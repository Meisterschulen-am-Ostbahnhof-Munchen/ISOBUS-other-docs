# PGN 65091
## PGN
**Parameter Group Number (PGN) 65091**, also known as **Primary or Rear Power Take-Off (RPTO)**, is used for transmitting data to the rear power take-off (PTO) in agricultural machinery. This message conforms to the ISOBUS standard ISO 11783.
### **PGN 65091 – Primary or Rear Power Take-Off (PTO)**
- **PG Label**: Primary or Rear Power Take-Off
- **PG Acronym**: RPTO
- **PG Notes**:
- Used for controlling the rear power take-off (PTO)
- Contains speeds, operating modes, and status information
- Critical for PTO-driven implements
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 67
- **Multipacket**: No
- **Transmission Rate**: 100 ms when engaged, otherwise on request
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **SP Start Bit**: See SPN Definitions
- **PG Document**: ISO 11783-7

### **Application Case**
Enables precise control of:

- Rear PTO-driven implements
- Speed control
- Operating mode control
