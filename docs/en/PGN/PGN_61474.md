# PGN 61474
## PGN
**Parameter Group Number (PGN) 61474**, also known as **Machine Selected Speed (MSS)**, transmits the operator-selected target speed and associated parameters. This message conforms to the ISOBUS standard ISO 11783.
### **PGN 61474 – Machine Selected Speed**
- **PG Label**: Machine Selected Speed
- **PG Acronym**: MSS
- **PG Notes**:
- Used for speed control systems
- Supports precision farming applications
- Typically sent by the tractor ECU
- **EDP**: 0
- **DP**: 0
- **PF**: 240
- **PS**: 34
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **SP Start Bit**: See SPN definitions
- **PG Document**: ISO 11783-7

### **Application Use**
Enables precise speed control for:

- Automatic steering systems
- Section control
- Precision farming operations

# **SPNs in PGN 61474 – Machine Selected Speed**

## **SPN 4305 – Machine Selected Speed**
- **SP Position**: Bits 1-2
- **SP Length**: 16 bits
- **Scaling**:
- Bits 1-8: 0.256 m/s per bit
- Bits 9-16: 0.001 m/s per bit
- **Range**: 0-64.255 m/s
- **Description**: Selected target speed

## **SPN 4306 – Machine Selected Distance**
- **SP Position**: Bits 3-6
- **SP Length**: 32 bits
- **Scaling**: 0.001 m per bit
- **Range**: 0-4211081.215 m
- **Description**: Distance traveled at selected speed

## **SPN 5818 – Machine selected speed exit/reason code**
- **SP Position**: Bits 7.1-7.6
- **SP Length**: 6 bits
- **States**: 64 possible status codes
- **Description**: Reason for speed change

## **SPN 4309 – Machine selected direction**
- **SP Position**: Bits 8.1-8.2
- **SP Length**: 2 bits
- **States**:
- 00: Forward
- 01: Reverse
- 10: Neutral
- 11: Invalid

## **SPN 4308 – Machine selected speed source**
- **SP Position**: Bits 8.3-8.5
- **SP Length**: 3 bits
- **States**: 8 possible sources
- **Description**: Origin of speed selection

## **SPN 4307 – Machine-selected speed limit status**
- **SP Position**: Bits 8.6-8.8
- **SP Length**: 3 bits
- **States**: 8 possible limiting states
- **Description**: Speed limiting status
