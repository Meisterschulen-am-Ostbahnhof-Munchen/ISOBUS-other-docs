# PGN 65093
## PGN
**Parameter Group Number (PGN) 65093**, also known as **Primary or Rear Hitch Status (RHS)**, transmits status information for the rear three-point linkage of tractors. This message conforms to the ISOBUS standard ISO 11783.
### **PGN 65093 – Primary or Rear Hitch Status**
- **PG Label**: Primary or Rear Hitch Status
- **PG Acronym**: RHS
- **PG Notes**:
- Used for monitoring the rear hitch
- Contains position, force, and status data
- Important for automatic depth control systems
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 69
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **SP Start Bit**: See SPN definitions
- **PG Document**: ISO 11783-7

### **Application Case**
Enables monitoring and control of:

- Rear hitch position
- Traction force measurement
- Automatic depth control systems

# **SPNs in PGN 65093 – Primary or Rear Hitch Status**

## **SPN 1873 – Rear Hitch Position**
- **SP Position**: Byte 1
- **SP Length**: 8 bits
- **Scaling**: 0.4% per bit
- **Range**: 0-100%
- **Description**: Current rear hitch position

## **SPN 5151 – Rear Hitch Position Limit Status**
- **SP Position**: 2.4-2.6 bits
- **SP Length**: 3 bits
- **States**: 8 possible limit statuses
- **Description**: Position limit status

## **SPN 1877 – Rear Hitch In-work Indication**
- **SP Position**: Bits 2.7-2.8
- **SP Length**: 2 bits
- **States**:
- 00: Not in work
- 01: In work
- 10: Transition
- 11: Error

## **SPN 1881 – Rear Nominal Lower Link Force**
- **SP Position**: Byte 3
- **SP Length**: 8 bits
- **Scaling**: 0.8% per bit
- **Offset**: -100%
- **Range**: -100% to +100%
- **Description**: Standardized pulling force

## **SPN 1879 – Rear Draft**
- **SP Position**: Bytes 4-5
- **SP Length**: 16 bits
- **Scaling**: 10N per bit
- **Offset**: -320,000 N
- **Range**: -320,000 to +322,550 N
- **Description**: Measured tractive force

## **SPN 5819 – Rear hitch exit/reason code**
- **SP Position**: Bits 6.1-6.6
- **SP Length**: 6 bits
- **States**: 64 possible status codes
- **Description**: Reason for state change
