# PGN 64770
## PGN
**Parameter Group Number (PGN) 64770**, also known as **All implements stop operations switch state (AISO)**, is an important ISO 11783-7 message for the emergency shutdown of all implements. This message is sent by the tractor to immediately stop all connected implements.

# **SPNs in PGN 64770 – All implements stop operations switch state (AISO)**

## **SPN 7443 – Stop All Implement Operations Transition Number**
- **SP Position**: Byte 7
- **SP Length**: 8 bits
- **Scaling**: 256 states per 8 bits
- **Range**: 0 to 255
- **Unit**: bit
- **Description**: Transition number for the stop operation (for sequencing)

## **SPN 5140 – Stop all implement operations**
- **SP Position**: Bits 8.1-8.2
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **States**:
- 00: Off (Normal operation)
- 01: On (Stop all attachments)
- 10: Error
- 11: Not available
- **Description**: Switch for emergency shutdown of all attachments
