# PGN 65096
## PGN
**Parameter Group Number (PGN) 65096**, which is referred to as **Wheel-based Speed and Distance (WBSD)**. This message is typically sent by a tractor ECU (Electronic Control Unit) on the implement bus in agricultural and construction machinery. It contains important data such as the measured wheel-based speed, a free-running odometer reading, the direction of travel, and the start/stop switch status.

# **SPNs in PGN 65096 – Wheel-based Speed and Distance (WBSD)**

The information you provided relates to the **Suspect Parameter Numbers (SPNs)** contained in **PGN 65096 (Wheel-based Speed and Distance – WBSD)**. Each SPN represents a specific parameter within the message. Here is a detailed breakdown of the SPNs:

---

## **SPN 1862 – Wheel-based machine speed**
- **SP Position in PG**: Bits 1-2
- **SP Length**: 16 Bits
- **Scaling**: 0.001 m/s per bit
- **Offset**: 0
- **Description**: Specifies the wheel-based speed of the machine in meters per second (m/s).

## **SPN 1863 – Wheel-based machine distance**
- **SP Position in PG**: Bits 3-6
- **SP Length**: 32 Bits
- **Scaling**: 0.001 m per bit
- **Offset**: 0
- **Description**: A free-running distance counter that indicates the distance traveled in meters (m).

## **SPN 1866 – Maximum Time of Tractor Power**
- **SP Position in PG**: Bit 7
- **SP Length**: 8 Bits
- **Scaling**: 1 minute per bit
- **Offset**: 0
- **Description**: Indicates the maximum time for which tractor power is maintained (in minutes).

## **SPN 1864 – Wheel-based machine direction**
- **SP Position in PG**: Bits 8.1-8.2
- **SP Length**: 2 Bits
- **Scaling**: 4 states per 2 bits
- **Offset**: 0
- **Description**: Indicates the direction of travel of the machine. The 4 possible states are:
- 00: Forward
- 01: Reverse
- 10: Neutral
- 11: Invalid

## **SPN 1865 – Key switch state**
- **SP Position in PG**: Bits 8.3-8.4
- **SP Length**: 2 Bits
- **Scaling**: 4 states per 2 bits
- **Offset**: 0
- **Description**: Indicates the state of the ignition switch. The 4 possible states are:
- 00: Off
- 01: On
- 10: Start
- 11: Invalid

## **SPN 5203 – Implement Start/Stop operations**
- **SP Position in PG**: Bits 8.5-8.6
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **Offset**: 0
- **Description**: Specifies the state of the start/stop operations for implements. The 4 possible states are:
- 00: Stop
- 01: Start
- 10: Pause
- 11: Invalid

## **SPN 5244 – Operator direction reversed**
- **SP Position in PG**: Bits 8.7-8.8
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **Offset**: 0
- **Description**: Indicates whether the operator direction is reversed. The 4 possible states are:
- 00: Normal
- 01: Reversed
- 10: Neutral
- 11: Invalid
