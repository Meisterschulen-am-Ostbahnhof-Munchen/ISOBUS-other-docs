# PGN 65095
## PGN
**Parameter Group Number (PGN) 65095**, also known as **Maintain Power (MP)**, controls the power supply to implements and ECUs after the ignition is switched off. This message is sent by the implement to inform the tractor whether and for how long the power supply should be maintained.
**Note**: This message is sent by the implement, not the tractor. It is used to control the power supply.
**Parameter Group Number (PGN) 65095**
### **PGN 65095 – Maintain Power (MP)**
- **PG Label**: Maintain Power
- **PG Acronym**: MP
- **PG Notes**:
- Sent when the ignition switches from ON to OFF
- Or when parameters change
- 6 SPNs, each with 2 bits (4 states)
- This is an implement-to-tractor message
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 71
- **Multipacket**: No
- **Transmission Rate**: As required after receiving the message indicating that the ignition switch has changed from the ON state to the OFF state, or on a change of parameter state
- **PG Data Length**: 8 Bytes
- **Default Priority**: 6
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **PG Document**: ISO 11783-7

### **Use Case**

This message is used for:

- Safe shutdown of implements
- Maintaining power supply after ignition is switched off
- Status message of implement states (Transport, Park, Ready, In Progress)
- Coordination between tractor and implement during shutdown

# **SPNs in PGN 65095 – Maintain Power (MP)**

## **SPN 1867 – Maintain ECU Power**
- **SP Position**: Bits 1.7-1.8
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **States**:
- 00: Off
- 01: On
- 10: Error
- 11: Not available
- **Description**: Requests maintenance of ECU Power Supply On

## **SPN 1868 – Maintain Actuator Power**
- **SP Position**: Bits 1.5-1.6
- **SP Length**: 2 Bits
- **Scaling**: 4 states per 2 bits
- **States**: Same as SPN 1867
- **Description**: Requests continued actuator power supply

## **SPN 1869 – Implement Transport State**
- **SP Position**: Bits 2.7-2.8
- **SP Length**: 2 Bits
- **Scaling**: 4 states per 2 bits
- **States**: Same as SPN 1867
- **Description**: Implement is in transport state

## **SPN 1870 – Implement Park State**
- **SP Position**: Bits 2.5-2.6
- **SP Length**: 2 Bits
- **Scaling**: 4 states per 2 bits
- **States**: As SPN 1867
- **Description**: Attachment is in parked state

## **SPN 1871 – Implement ready-to-work state**
- **SP Position**: Bits 2.3-2.4
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **States**: As SPN 1867
- **Description**: Attachment is ready for work

## **SPN 7447 – Implement in-work state**
- **SP Position**: Bits 2.1-2.2
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **States**: As SPN 1867
- **Description**: Attachment is in operation

---

### **Summary**
- The PGN 65095 contains 6 SPNs for power supply and status management.
- All SPNs use 2 bits with 4 states.
- This message is sent from the implement to the tractor.
- Essential for safely shutting down implements.
