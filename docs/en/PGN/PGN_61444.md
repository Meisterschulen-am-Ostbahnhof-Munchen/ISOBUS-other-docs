# PGN 61444

## PGN

**Parameter Group Number (PGN) 61444**, also known as **Electronic Engine Controller 1 (EEC1)**, is one of the most important J1939 messages and is typically sent on the ISOBUS implement bus of tractors. It contains basic engine parameters such as speed, torque, and operating mode.


**Parameter Group Number (PGN) 61444**, also known as **Electronic Engine Controller 1 (EEC1)**, is one of the most important J1939 messages and is typically sent on the ISOBUS implement bus of tractors. It contains basic engine parameters such as speed, torque, and operating mode. ### **PGN 61444 – Electronic Engine Controller 1 (EEC1)**

- **PG Label**: Electronic Engine Controller 1

- **PG Acronym**: EEC1

- **PG Notes**:

- J1939 message, but typically also sent via ISOBUS

- Contains engine speed, torque, and operating mode

- Sent by the engine ECU

- Important for implement control and power calculation

- **EDP**: 0

- **DP**: 0

- **PF**: 240
- **PS**: 3
- **Multipacket**: No
- **Transmission Rate**: 10 ms (engine running) / 1 s (engine stopped)

- **PG Data Length**: 8 Bytes
- **Default Priority**: 3

- **PG Reference**: J1939DA

### **Technical Details**

- **PG Document**: J1939DA

### **Use Case**

This message is used for:

- Engine speed monitoring
- Power calculation (RPM x Torque)
- Automatic implementation adjustment to engine load
- Speed control and limiting
- Diagnostics and fault detection

# **SPNs in PGN 61444 – Electronic Engine Controller 1 (EEC1)**

## **SPN 899 – Engine Torque Mode**

- **SP Position**: Bits 1.1-1.4

- **SP Length**: 4 bits

- **Scaling**: 16 states per 4 bits

- **Range**: 0 to 15

- **Unit**: bit

- **Description**: Current engine torque mode (e.g., 0 = No demand, 1 = Accelerator pedal, 2 = Cruise control, etc.)

## **SPN 4154 – Actual Engine - Percent Torque (Fractional)**

- **SP Position**: Bits 1.5-1.8

- **SP Length**: 4 Bits

- **Scaling**: 0.125%/Bit

- **Offset**: 0

- **Range**: 0 to 1.875%

- **Unit**: %

- **Description**: Fractional portion of the actual torque (supplements SPN 513)

## **SPN 512 – Driver's Demand Engine - Percent Torque**

- **SP Position**: Byte 2

- **SP Length**: 8 Bits

- **Scaling**: 1%/Bit

- **Offset**: -125

- **Range**: -125 to 125%

- **Unit**: %

- **Description**: Torque requested by the driver (e.g., accelerator pedal)

## **SPN 513 – Actual Engine - Percent Torque**

- **SP Position**: Byte 3

- **SP Length**: 8 Bits

- **Scaling**: 1%/Bit

- **Offset**: -125

- **Range**: -125 to 125%

- **Unit**: %

- **Description**: Current engine torque (integer part)

## **SPN 190 – Engine Speed**

- **SP Position**: Bytes 4-5

- **SP Length**: 16 Bits

- **Scaling**: 0.125 rpm/Bit

- **Offset**: 0

- **Range**: 0 to 8,031.875 rpm

- **Unit**: rpm

- **Description**: Current engine speed

## **SPN 1483 – Source Address of Controlling Device for Engine Control**

- **SP Position**: Byte 6

- **SP Length**: 8 bits

- **Scaling**: 1 per bit

- **Offset**: 0

- **Range**: 0 to 255

- **Unit**:

- **Description**: Address of the control unit that controls the engine

## **SPN 1675 – Engine Starter Mode**

- **SP Position**: Bits 7.1-7.4

- **SP Length**: 4 bits

- **Scaling**: 16 states per 4 bits

- **Range**: 0 to 15

- **Unit**: bit

- **Description**: Starter mode (e.g., 0 = starter inactive, 1 = starter active, etc.)

## **SPN 2432 – Engine Demand – Percent Torque**

- **SP Position**: Byte 8

- **SP Length**: 8 bits

- **Scaling**: 1 %/Bit

- **Offset**: -125

- **Range**: -125 to 125%

- **Unit**: %

- **Description**: Torque requested by the engine control unit

---

### **Summary**

- PGN 61444 contains 8 SPNs for engine control and monitoring.

- Main parameters: Engine Speed (SPN 190) and Actual Engine Torque (SPN 513).

- Although a J1939 message, it is typically also sent via ISOBUS.

- The message is sent at a rate of 10 ms (with the engine running).

- For complete details, see J1939DA.
