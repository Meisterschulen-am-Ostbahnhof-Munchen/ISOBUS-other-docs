# PGN 65267
## PGN

**Parameter Group Number (PGN) 65267**
### **PGN 65267 – Vehicle Position 1 (VP1)**

- **PG Label**: Vehicle Position 1
- **PG Acronym**: VP1
- **PG Notes**:
- Typically sent by GPS modules
- Contains basic geographic coordinates
- Important for positioning and navigation
- Often combined with other navigation PGNs
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 243
- **Multipacket**: No
- **Transmission Rate**: 100-1000 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 6
- **PG Reference**: SAE J1939-71

### **Technical Details**
- **SP Start Bit**: See SPN definitions
- **PG Document**: SAE J1939-71

### **Use Case**
Enables the transmission of:

- Latitude
- Longitude
- Used for basic positioning

# **SPNs in PGN 65267 – Vehicle Position 1**

## **SPN 584 – Latitude**
- **SP Position**: Bits 1-4
- **SP Length**: 32 bits
- **Scaling**: 1e-7 degrees per bit
- **Range**: ±90° (North/South)
- **Accuracy**: 0.0000001°
- **Description**: Latitude in decimal degrees

## **SPN 585 – Longitude**
- **SP Position**: Bits 5-8
- **SP Length**: 32 bits
- **Scaling**: 1e-7 Deg per bit
- **Range**: ±180° (East/West)
- **Accuracy**: 0.0000001°
- **Description**: Geographic longitude in decimal degrees

- Includes 2 basic position parameters
- High-precision positioning (up to 1.1 cm accuracy)
- Often combined with PGN 65256 (VDS)
- Typical update rate: 100-1000 ms
