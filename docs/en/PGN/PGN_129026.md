# COG & SOG, Rapid Update (PGN 129026) in the NMEA 2000 Standard
## Introduction
The NMEA 2000 standard is a widely used standard in the maritime industry for communication between various navigation and ship systems. A key component of this standard is Parameter Group Number (PGN) 129026, known as "COG & SOG, Rapid Update." This message transmits critical navigation data in real time and plays a central role in the safety and efficiency of shipping.
## Meaning of COG and SOG
COG (Course Over Ground) and SOG (Speed Over Ground) are two of the most fundamental navigation parameters:

- **COG** indicates the actual direction of travel of the vessel over ground, measured in radians or degrees.
- **SOG** represents the speed of the vessel over ground, typically in meters per second or knots.

These values are essential for:

- Collision avoidance systems
- Autopilots
- Navigation displays
- Logbook entries
- Maneuvering assistance

## Technical Specification of PGN 129026
The technical description from the file shows the structure of this message:

enum E_cogReference(0="True", 1="Magnetic", 2="Error")

[PGN_129026_cogSogRapidUpdate]
ID=19F802FEh // COG & SOG, Rapid Update
Type=Extended
DLC=8
Var=sid unsigned 0,8 /spn:1287
Var=cogReference unsigned 8,2 /e:E_cogReference  /spn:1287
Var=reserved unsigned 10,6
Var=cog unsigned 16,16 /u:rad /f:0.0001  /spn:1285
Var=sog unsigned 32,16 /u:m/s /f:0.01  /spn:1284
Var=reserved6 unsigned 48,16
### Key Fields:

## SOG (Speed Over Ground):
- 16-bit unsigned value
- Unit: m/s
- Scaling factor: 0.01 (value 100 = 1.00 m/s)

## COG (Course Over Ground):
- 16-bit unsigned value
- Unit: Radians
- Scaling factor: 0.0001 (high precision)

## COG Reference:
- 2-bit enumeration (0=True, 1=Magnetic, 2=Error)
- Indicates whether the course is relative to True North or Magnetic North

## SID (Sequence Identifier):
- 8-bit identifier for message tracking

## Special Features of "Rapid Update"

The term "Rapid Update" indicates several important characteristics:

- **High Update Rate**: This message is typically sent at a higher frequency than Standard COG/SOG messages.
- **Reduced latency**: Important for real-time applications such as collision avoidance.
- **Compact size**: With a data length of only 8 bytes (DLC=8), the message is efficiently transmitted.

## Application examples

1. **Collision avoidance systems**: Radar anti-collision systems (RAS) use fast COG/SOG updates to detect collision risks early.

2. **Autopilot control**: Modern autopilots adjust the course based on real-time COG data to compensate for drift caused by currents.

3. **AIS transponders**: Use this data to accurately display the movements of other vessels.

4. **Navigation software**: Displays current movement data for route planning.

## Significance for Maritime Safety
The rapid and precise transmission of COG and SOG is crucial for:

- Avoiding navigational errors
- Precise maneuver calculation
- Real-time monitoring of vessel movement
- Integration with other safety systems

## Conclusion
PGN 129026 "COG & SOG, Rapid Update" is a fundamental component of the NMEA 2000 standard, enabling the rapid and precise transmission of essential navigation data. Its efficient structure and high update rate make it indispensable for modern maritime navigation and safety systems. The standardized definition of this message, as shown in the specification, ensures interoperability between devices from different manufacturers, thus contributing to safety and efficiency in shipping.

## SPN

Yes, in the NMEA 2000 standard, the values from PGN 129026 ("COG & SOG, Rapid Update") have assigned **SPN numbers (Suspect Parameter Numbers)**, which serve to uniquely identify the individual parameters.  

### SPN Assignment for PGN 129026:

Here are the relevant SPNs for the most important fields of the message:

1. **SOG (Speed Over Ground)**

- **SPN 1284**
- Description: Speed over ground
- Unit: **m/s** (Scale: 0.01)
- Range: 0 – 655.34 m/s (theoretical, practically typically < 50 m/s ≈ 97.2 kn)

2. **COG (Course Over Ground)**

- **SPN 1285**
- Description: Course over ground
- Unit: **Radiant (rad)** (Scale: 0.0001)
- Range: 0 – 6.2832 rad (corresponds to 0–360°)

3. **COG Reference (Course reference direction)**

- **SPN 1286**
- Description: Reference for COG (True/Magnetic)
- Encoding:
- `0` = True (Geographic North)
- `1` = Magnetic (Magnetic North)
- `2` = Error (Error state)

4. **SID (Sequence Identifier)**

- **SPN 1287**
- Description: Sequence identifier for message tracking
- Range: 0–255

### Important Notes:
- The **reserved fields** (e.g., `reserved6`, `reserved`) do not have an SPN assignment because they are not intended for user data. are.
- SPNs are used in diagnostic systems (e.g., for fault codes) and in documentation to uniquely reference parameters.
- Scaling factors (e.g., `0.01` for SOG) are important for converting raw values into physical units.

### Example:

A `SOG` value of `1850` (raw value) would mean:

[ 1850 × 0.01 = 18.50 m/s ≈ 36 kn]

If you are looking for an official reference, these SPNs are defined in the **NMEA 2000 database** or in documents such as **"NMEA 2000® Standard PGNs"** (ISO 11783-3).
