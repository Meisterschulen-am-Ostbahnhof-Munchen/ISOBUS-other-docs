# PGN 65056 - Auxiliary Valve 0 Measured Flow
## PGN
**Parameter Group Number (PGN) 65056**, also known as **Auxiliary valve 0 measured flow (AV00MF)**, provides the measured oil flow and pressure for auxiliary valve 0. This message is sent by the tractor and contains actual values for the hydraulic control system.
**
### **PGN 65056 – Auxiliary valve 0 measured flow (AV00MF)**
- **PG Label**: Auxiliary valve 0 measured flow
- **PG Acronym**: AV00MF
- **PG Notes**:
- Contains measured oil flows for the extend and retract ports
- Pressure values for the extend, retract, and return ports
- Flow limit status
- Sent by the tractor ECU
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 32
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

---

# **SPNs in PGN 65056 – Auxiliary valve 0 measured flow (AV00MF)**

## **SPN 1899 – Auxiliary valve number 0 extends port measured flow**
- **SP Position**: Byte 1
- **SP Length**: 8 bits
- **Scaling**: 1%/bit
- **Offset**: -125
- **Range**: -125 to 125%
- **Unit**: %
- **Description**: Measured oil flow at the extend port (extend)

## **SPN 1900 – Auxiliary valve number 0 retract port measured flow**
- **SP Position**: Byte 2
- **SP Length**: 8 bits
- **Scaling**: 1%/bit
- **Offset**: -125
- **Range**: -125 to 125%
- **Unit**: %
- **Description**: Measured oil flow on Retract port

## **SPN 1904 – Auxiliary valve number 0 extends port pressure**
- **SP Position**: Bytes 3-4
- **SP Length**: 16 bits
- **Scaling**: 5 kPa/bit
- **Offset**: 0
- **Range**: 0 to 321,275 kPa
- **Unit**: kPa
- **Description**: Printing on the extend port

## **SPN 1905 – Auxiliary valve number 0 retract port pressure**
- **SP Position**: Bytes 5-6
- **SP Length**: 16 bits
- **Scaling**: 5 kPa/bit
- **Offset**: 0
- **Range**: 0 to 321,275 kPa
- **Unit**: kPa
- **Description**: Pressure on the retract port

## **SPN 1906 – Auxiliary valve number 0 return port pressure**
- **SP Position**: Byte 7
- **SP Length**: 8 Bits
- **Scaling**: 16 kPa/Bit
- **Offset**: 0
- **Range**: 0 to 4000 kPa
- **Unit**: kPa
- **Description**: Pressure at the return port

## **SPN 5160 – Auxiliary valve number 0 measured flow limit status**
- **SP Position**: Bits 8.6-8.8
- **SP Length**: 3 Bits
- **Scaling**: 8 states per 3 bits
- **Range**: 0 to 7
- **Unit**: bit
- **Description**: Flow limit status

---

### **Summary**
- The PGN 65056 contains 6 SPNs for valve 0.
- Measured flow rates and pressures for all ports.
- Analogous PGNs exist for valves 1-15 (PGN 65057-65071).
- Supplements the Estimated Flow message (PGN 65040) with actual values.
