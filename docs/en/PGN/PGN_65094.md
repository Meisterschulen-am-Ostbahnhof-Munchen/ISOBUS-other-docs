# PGN 65094
## PGN
**Parameter Group Number (PGN) 65094**, also known as **Secondary or Front Hitch Status (FHS)**, transmits status information for the front three-point linkage of tractors. This message complies with the ISOBUS standard ISO 11783.
### **PGN 65094 – Secondary or Front Hitch Status**
- **PG Label**: Secondary or Front Hitch Status
- **PG Acronym**: FHS
- **PG Notes**:
- Used for monitoring the front hydraulics
- Contains position, force, and status data
- Important for front-mounted implements
- Complementary to PGN 65093 (Rear Hitch Status)
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 70
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **SP Start Bit**: See SPN definitions
- **PG Document**: ISO 11783-7

### **Application Case**
Enables monitoring and control of:

- Front hydraulic position
- Traction measurement for front implements
- Automatic control systems for front-mounted implements

# **SPNs in PGN 65094 – Secondary or Front Hitch Status**

## **SPN 1872 – Front Hitch Position**
- **SP Position**: Byte 1
- **SP Length**: 8 bits
- **Scaling**: 0.4% per bit
- **Range**: 0-100%
- **Description**: Current position of the front hitch

## **SPN 5150 – Front Hitch Position Limit status**
- **SP Position**: 2.4-2.6 bits
- **SP Length**: 3 bits
- **States**: 8 Possible Limiting States
- **Description**: Front Hitch Position Limiting State

## **SPN 1876 – Front Hitch In-work Indication**
- **SP Position**: Bits 2.7-2.8
- **SP Length**: 2 Bits
- **States**:
- 00: Not in work
- 01: In work
- 10: Transition
- 11: Error

## **SPN 1880 – Front Nominal Lower Link Force**
- **SP Position**: Byte 3
- **SP Length**: 8 Bits
- **Scaling**: 0.8% per bit
- **Offset**: -100%
- **Range**: -100% to +100%
- **Description**: Normalized front hitch force

## **SPN 1878 – Front Draft**
- **SP Position**: Bytes 4-5
- **SP Length**: 16 Bits
- **Scaling**: 10 N per Bit
- **Offset**: -320.000 N
- **Range**: -320.000 to +322.550 N
- **Description**: Measured tractive force at the front hitch

## **SPN 5816 – Front hitch exit/reason code**
- **SP Position**: Bits 6.1-6.6
- **SP Length**: 6 Bits
- **States**: 64 possible status codes
- **Description**: Reason for front hitch state change
