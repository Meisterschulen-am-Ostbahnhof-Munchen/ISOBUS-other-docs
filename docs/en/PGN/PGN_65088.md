# PGN 65088

## PGN

**Parameter Group Number (PGN) 65088**, also known as **Lighting Data (LD)**, transmits the status of all lighting and illumination functions of a tractor and connected implements. This message conforms to the ISOBUS standard ISO 11783.

### **PGN 65088 – Lighting Data (LD)**

- **PG Label**: Lighting Data
- **PG Acronym**: LD
- **PG Notes**:

- Sent as requested

- Contains the on/off status of all vehicle lights

- Each light is represented by 2 bits (4 states)

- Important for controlling accessories and lighting management

- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 64
- **Multipacket**: No
- **Transmission Rate**: As requested
- **PG Data Length**: 8 Bytes
- **Default Priority**: 6
- **PG Reference**: ISO 11783-7

### **Technical Details**

- **SP Start Bit**: See SPN Definitions

- **PG Document**: ISO 11783-7

### **Use Case**

This message is used for:

- Monitoring and control of vehicle lighting
- Synchronization of implement lighting with tractor lighting
- Automatic lighting control systems
- Diagnostics and fault detection in lighting systems

### **Summary**

- The PGN 65088 contains 31 SPNs that represent the status of various lighting functions.

- Each SPN uses 2 bits with 4 possible states (Off, On, Error, Not available).

- The message is sent on request and has a data length of 8 bytes.

- This PGN is essential for coordinating lighting systems between the tractor and implements.
