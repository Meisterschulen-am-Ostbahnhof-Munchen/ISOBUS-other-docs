# PGN 65255**

**Parameter Group Number (PGN) 65255**, also known as **Vehicle Hours (VH)**, contains operating hour information for the vehicle and the power take-off (PTO). This information is important for maintenance and performance analysis.

**

** ### **PGN 65255 – Vehicle Hours (VH)**

- **PG Label**: Vehicle Hours
- **PG Acronym**: VH
- **PG Notes**:

- Contains total vehicle operating hours

- Contains power take-off (PTO) operating hours

- Important for maintenance intervals

- J1939 message, typically also sent via ISOBUS

- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 231
- **Multipacket**: No
- **Transmission Rate**: On request
- **PG Data Length**: 8 Bytes
- **Default Priority**: 6
- **PG Reference**: J1939DA

### **Technical Details**

- **PG Document**: J1939DA

### **Use Case**
This message is used for:

- Maintenance Interval Monitoring
- Performance Analysis and Logging
- Operating Hour Recording for Attachments
- Documentation in Task Controller and FMIS

# **SPNs in PGN 65255 – Vehicle Hours (VH)**

## **SPN 246 – Total Vehicle Hours**

- **SP Position**: Bytes 1-4

- **SP Length**: 32 Bits

- **Scaling**: 0.05 h/Bit

- **Offset**: 0

- **Range**: 0 to 210,554,060.75 h

- **Unit**: h

- **Description**: Total operating hours of the vehicle

## **SPN 248 – Total Power Takeoff Hours**

- **SP Position**: Bytes 5-8

- **SP Length**: 32 Bits

- **Scaling**: 0.05 h/Bit

- **Offset**: 0

- **Range**: 0 to 210,554,060.75 h

- **Unit**: h

- **Description**: Total Power Take-Off (PTO) operating hours
