# PGN 65040 - Auxiliary Valve 0 Estimated Flow
## PGN
**Parameter Group Number (PGN) 65040**, also known as **Auxiliary valve 0 estimated flow (AV00EF)**, provides the estimated oil flow and valve status for auxiliary valve 0. This message is sent by the tractor and is important for the hydraulic control of implements.
**
### **PGN 65040 – Auxiliary valve 0 estimated flow (AV00EF)**
- **PG Label**: Auxiliary valve 0 estimated flow
- **PG Acronym**: AV00EF
- **PG Notes**:
- Contains estimated oil flow for extend and retract ports
- Valve status and fail-safe mode
- High-resolution flow value
- Sent by the tractor ECU
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 16
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

---

# **SPNs in PGN 65040 – Auxiliary valve 0 estimated flow (AV00EF)**

## **SPN 1901 – Auxiliary valve 0 extend port estimated flow**
- **SP Position**: Byte 1
- **SP Length**: 8 bits
- **Scaling**: 1%/bit
- **Offset**: -125
- **Range**: -125 to 125%
- **Unit**: %
- **Description**: Estimated oil flow at the extend port (extend)

## **SPN 1902 – Auxiliary valve 0 retract port estimated flow**
- **SP Position**: Byte 2
- **SP Length**: 8 bits
- **Scaling**: 1%/bit
- **Offset**: -125
- **Range**: -125 to 125%
- **Unit**: %
- **Description**: Estimated oil flow on Retract Port

## **SPN 1903 – Auxiliary valve number 0 valve state**
- **SP Position**: Bits 3.1-3.4
- **SP Length**: 4 bits
- **Scaling**: 16 states per 4 bits
- **Range**: 0 to 15
- **Unit**: bit
- **Description**: Current valve state (16 different states)

## **SPN 1910 – Auxiliary valve 0 fail safe mode**
- **SP Position**: Bits 3.7-3.8
- **SP Length**: 2 bits
- **Scaling**: 4 states per 2 bits
- **States**:
- 00: Off
- 01: On
- 10: Error
- 11: Not available
- **Description**: Fail-safe mode of the valve

## **SPN 5161 – Auxiliary valve number 0 estimated flow limit status**
- **SP Position**: Bits 4.6-4.8
- **SP Length**: 3 bits
- **Scaling**: 8 states per 3 bits
- **Range**: 0 to 7
- **Unit**: bit
- **Description**: Flow limitation status

## **SPN 5800 – Auxiliary valve 0 exit/reason code**
- **SP Position**: Bits 5.1-5.6
- **SP Length**: 6 bits
- **Scaling**: 64 states per 6 bits
- **Range**: 0 to 63
- **Unit**: bit
- **Description**: Exit/Reason Code for the valve

## **SPN 9732 – Auxiliary valve 0 estimated flow (high resolution)**
- **SP Position**: Bytes 7-8
- **SP Length**: 16 Bits
- **Scaling**: 0.004%/Bit
- **Offset**: -125
- **Range**: -125 to 132.02%
- **Unit**: %
- **Description**: High-resolution estimated oil flow

---

### **Summary**
- The PGN 65040 contains 7 SPNs for valve 0.
- Estimated flows for the extend and retract ports.
- High-resolution value for more precise control.
- Analogous PGNs exist for valves 1-15 (PGN 65041-65055).
