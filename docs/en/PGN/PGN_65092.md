# PGN 65092
## PGN
**Parameter Group Number (PGN) 65092**, also known as **Secondary or Front Power Take-Off Output Shaft (FPTO)**, transmits data to the front power take-off (PTO) shaft in modern tractors. This message conforms to the ISOBUS standard ISO 11783.
### **PGN 65092 – Secondary or Front Power Take-Off Output Shaft (FPTO)**
- **PG Label**: Secondary or Front Power Take-Off Output Shaft
- **PG Acronym**: FPTO
- **PG Notes**:
- Used for controlling the front PTO
- Contains speeds, operating modes, and status information
- Critical for front-mounted PTO devices
- Complementary to PGN 65091 (Rear PTO)
- **EDP**: 0
- **DP**: 0
- **PF**: 254
- **PS**: 68
- **Multipacket**: No
- **Transmission Rate**: 100 ms when engaged, otherwise on request
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: ISO 11783-7

### **Technical Details**
- **SP Start Bit**: See SPN definitions
- **PG Document**: ISO 11783-7

### **Application Case**
Enables precise control of:

- Front PTO-driven implements
- Speed control for front-mounted implements
- Automatic operating mode switching

# **SPNs in PGN 65092 – Secondary or Front Power Take-Off Output Shaft**

## **SPN 1882 – Front PTO output shaft speed**
- **SP Position**: Bits 1-2
- **SP Length**: 16 bits
- **Scaling**: 0.125 rpm per bit
- **Range**: 0-8031.875 rpm
- **Accuracy**: ±0.125 rpm
- **Description**: Current speed of the Front PTO

## **SPN 1884 – Front PTO Output Shaft Speed Set Point**
- **SP Position**: Bits 3-4
- **SP Length**: 16 Bits
- **Scaling**: 0.125 rpm per bit
- **Description**: Target speed of the front PTO

## **SPN 5152 – Front PTO Engagement Request Status**
- **SP Position**: Bits 5.1-5.2
- **SP Length**: 2 Bits
- **States**:
- 00: Off
- 01: On
- 10: Pending
- 11: Error

## **SPN 1891 – Front Power Take Off Economy Mode**
- **SP Position**: Bits 5.3-5.4
- **SP Length**: 2 Bits
- **States**:
- 00: Normal Mode
- 01: Economy Mode
- 10: Reserved
- 11: Invalid

## **SPN 1889 – Front Power Take Off Mode**
- **SP Position**: Bits 5.5-5.6
- **SP Length**: 2 Bits
- **States**:
- 00: Ground speed mode
- 1: Engine speed mode
- 10: Mixed mode
- 11: Invalid

## **SPN 1888 – Front Power Take Off Engagement**
- **SP Position**: Bits 5.7-5.8
- **SP Length**: 2 Bits
- **States**:
- 00: Disengaged
- 01: Engaged
- 10: Transition
- 11: Fault

## **SPN 5155 – Front PTO shaft speed limit status**
- **SP Position**: Bits 6.2-6.4
- **SP Length**: 3 bits
- **States**: 8 possible limiting states
- **Description**: Speed limiting status

## **SPN 5154 – Front PTO Economy mode request status**
- **SP Position**: Bits 6.5-6.6
- **SP Length**: 2 bits
- **States**: 4 possible request states

## **SPN 5153 – Front PTO mode request status**
- **SP Position**: Bits 6.7-6.8

## **SPN 5817 – Front PTO exit/reason code**
- **SP Position**: Bits 7.1-7.6
