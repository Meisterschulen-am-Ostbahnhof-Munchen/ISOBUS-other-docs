# PGN 65265
## PGN
**Parameter Group Number (PGN) 65265**, also known as **Cruise Control/Vehicle Speed 1 (CCVS1)**, is an important J1939 message containing information about vehicle speed, cruise control, and various switch states. It is also typically transmitted on the ISOBUS implement bus of tractors.

**Parameter Group Number (PGN) 65265** ### **PGN 65265 – Cruise Control/Vehicle Speed 1 (CCVS1)**

- **PG Label**: Cruise Control/Vehicle Speed 1
- **PG Acronym**: CCVS1
- **PG Notes**:
- J1939 message, but is also typically sent via ISOBUS
- Contains Wheel-Based Vehicle Speed
- Cruise control switch and states
- Brake, clutch, and parking brake switches
- Sent by the tractor ECU
- **EDP**: 0
- **DP**: 0
- **PF**: 240
- **PS**: 4
- **Multipacket**: No
- **Transmission Rate**: 100 ms
- **PG Data Length**: 8 Bytes
- **Default Priority**: 3
- **PG Reference**: J1939DA

### **Technical Details**
- **PG Document**: J1939DA

### **Use Case**

This message is used for:

- Vehicle speed monitoring
- Cruise control functions
- Brake and clutch status detection
- Parking brake switch evaluation
- Speed control of attachments
